# Tasks

Implement only after `native-source-routing` is integrated. All tests below use production model/admission seams; fixture injection stays private or `#[cfg(test)]`. The numbered design decisions describe scope; exact Rust signatures are frozen at the first model/runtime handoff, before dependent UI edits. No real external SSH host is needed for automated acceptance.

Implementation split: the first tranche is tasks 1.1–1.3 under the unchanged local workflow, with a read-only review of the actual shared-model extraction. The core owner then freezes the NR1 read seam and NR2 command/update shape before GPUI work. Core/transport ownership covers groups 2–5; a separate GPUI owner can implement group 6 against that frozen seam and scripted source presentations while core lifecycle tests land. Integrate at group 7; do not hand UI an unfinished authority lookup that encourages current-source fallback. This sequencing is an internal implementation checkpoint, not a separate claim that remote behavior is complete.
